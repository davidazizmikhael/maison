# Store listing (EN + FR)

## ⚠️ Name check result (Sep 2, 2026)

No third-party app owns the bare name "Maison" — but **"Maison" is Apple's own
Home app display name in French locales**, and TELUS ships "Maison connectée"
in Canada. In the Québec store, an app named just "Maison" reads as Apple Home.
Keep the brand, qualify the listing name (App Store allows 30 chars):

- EN name: **Maison: Home Logbook** (20 chars)
- FR name: **Maison : carnet du domicile** (27 chars)
- Alternates if review objects: "Maison — Warranty & Home Log", "MaisonLog".
